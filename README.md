# 🌌 Quantum Image Encryption & Decryption
### _Hybrid Classical–Quantum Cipher using PNEQR, Lorenz Chaos & 5D Hyperchaotic System_

---

## ⚡ Overview
This project implements a **high-security quantum-inspired image encryption system** that combines:

- **PNEQR (Probabilistic NEQR)** – efficient quantum image representation  
- **Lorenz chaotic shuffling** – highly sensitive pixel permutation  
- **5D Hyperchaotic system** – massive key space for secure key-stream generation  
- **Dynamic quantum rotation gates** – block-wise rotations with varying angles  
- **Quantum perturbation simulation** – mimics realistic quantum energy behavior  

The model achieves excellent resistance against differential and statistical attacks.


---

## 🎯 Key Features

### 🔹 PNEQR Image Representation
- Uses **fewer qubits** than NEQR  
- Supports **RGB + grayscale**  
- More accurate than FRQI for color images  

### 🔹 Encryption Workflow
1. Quantum encoding via PNEQR  
2. Lorenz-chaotic pixel shuffling  
3. 5D hyperchaotic key-stream generation  
4. Dynamic 4×4 block quantum rotation  
5. Perturbation applied to simulate natural quantum behavior  

### 🔹 Security Highlights
- **NPCR = 100%**  
- **UACI ≈ 33%**  
- **Uniform histogram**  
- **Entropy ≈ 8**
